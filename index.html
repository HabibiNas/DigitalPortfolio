Portfolio Reflection

So far, my digital portfolio has come together much better than I initially expected. At first, I wasn’t sure how to structure the layout, but after working through GitHub Pages and experimenting with different designs, I feel more confident in how everything is organized. I am satisfied with the overall layout and navigation because it is simple and easy to follow, which makes it user-friendly for potential employers. I also chose a clean color scheme with dark and light contrast, which helps keep the site professional while still visually appealing. The fonts I used are clear and readable, which was something I paid attention to after realizing how important readability is for a portfolio.

Through this process, I learned how to build and publish a website using GitHub Pages, as well as how important design choices are in presenting information effectively. One of the more challenging aspects was understanding how to structure the HTML and make the site look polished instead of basic. Moving forward, I still want to improve the visual design and add more detailed project content. Overall, this assignment helped me better understand how to present myself professionally online and gave me a strong starting point for future improvements.
